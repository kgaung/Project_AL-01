# Abyssal Leviathan-01

A static mission report website for **Abyssal Leviathan-01**, a fictional deep-sea research submersible created by KANEDEV Marine Systems.

## Overview

This project is a stylized HTML and CSS presentation of a fictional underwater exploration mission, built around a concept design and specification document for an autonomous bioshaped submersible.

## What is included

- `abyssal-leviathan-01.html` — the main landing page with mission narrative, technical details, and visual layout.
- `assets/submarine-render.png` — hero render image used in the page.
- `assets/submarine-sketch.png` — concept cutaway sketch used in the blueprint section.

## Project highlights

- Mission report for the **Abyssal Leviathan-01** expedition to the **Shinkai Rift Zone**.
- Depth-rated design details for a **6,000 m operational** submersible.
- Autonomous onboard AI system for **survey planning, obstacle avoidance, and science reasoning**.
- Biomimetic propulsion with a **biomimetic tail**, articulated control surfaces, and low-drag hull.
- Technical specifications table, timeline log, outcomes, and design narrative.

## View locally

Open `abyssal-leviathan-01.html` in your browser to preview the project.

## Notes

This is a concept showcase rather than a working application. The page is intentionally designed as a polished narrative and specification document for the fictional KANEDEV platform.
